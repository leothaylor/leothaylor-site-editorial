# SHOT LIBRARY — REQUIRED PRODUCT SERIES

## Default series
Unless the user requests fewer views, the MASTER PROMPT should request the following coherent image set.

# SHOT 01 — HERO_3Q
Purpose: premium commercial hero image.
- vertical 4:5;
- ghost mannequin or invisible-form presentation;
- full jacket + pants;
- 3/4 front angle;
- neutral light gray studio background;
- belt correctly tied;
- small glimpse of interior art through collar opening;
- shoulder emblem visible;
- realistic pearl weave texture;
- high-end e-commerce/editorial lighting.

No person is necessary.

# SHOT 02 — OPEN_INTERIOR_FULL
Purpose: reveal the fusion.
- vertical 4:5 or near-square depending composition;
- jacket fully open;
- sleeves extended naturally;
- front-facing orthographic / flat-lay-like presentation;
- hero artwork dominates inner-back panel;
- inner side panels continue secondary motifs;
- outer sleeves remain product base color;
- lapel forms a clean frame around the art;
- visible seams and textile texture.

This is the most important shot for reference fidelity.

# SHOT 03 — FRONT_ORTHO_FULL
Purpose: verify exterior restraint.
- vertical 4:5;
- full gi;
- straight-on front;
- neutral studio;
- same belt;
- same shoulder emblem;
- same labels;
- interior hero art mostly hidden;
- only realistic collar glimpse if applicable.

# SHOT 04 — BACK_ORTHO_FULL
Purpose: verify rear branding and continuity.
- vertical 4:5;
- straight-on back;
- same base color and proportions;
- locked upper-back emblem;
- locked sleeve patch if visible;
- small lower-hem label if defined;
- no giant exterior hero art.

# SHOT 05 — INTERIOR_HERO_CLOSE
Purpose: prove art fidelity.
- close product view of opened jacket;
- crop emphasizes hero artwork, lapel frame and textile behavior;
- art must visibly follow folds and seams;
- enough outer fabric visible to prove it is inside the same kimono.

# SHOT 06 — DETAIL_MACRO_BOARD
Purpose: sell construction quality.
Create one clean 2x2 or asymmetric four-panel macro board showing:
1. lapel stitching + subtle inner-art glimpse;
2. shoulder/sleeve emblem thread or weave;
3. woven lower-hem label + nearby interior print edge;
4. black belt knot + rank/red end detail.

All details must match the MASTER PRODUCT.

# SHOT 07 — PRODUCT_BOARD
Purpose: technical-commercial overview.
Single clean board showing the same product in:
- open interior;
- front;
- back;
- optional hero 3/4 inset.
Use one colorway only unless the user explicitly requests color variants.
No new design elements.

# SHOT 08 — MATERIAL_MACRO
Purpose: textile proof.
- extreme close-up of pearl weave exterior transitioning to printed interior material;
- stitches, thread relief, woven patch edges, print penetration;
- realistic fabric fibers;
- no CGI plastic shine.

## Studio family
Default:
- seamless light gray / warm-neutral background;
- soft large-area lighting;
- gentle product shadow;
- accurate textile exposure;
- no dramatic environment;
- no floating particles;
- no external aura.

The reference art may contain dramatic effects inside the print. The studio itself stays controlled.

## Presentation rule
The series must feel like one luxury product campaign and product-development presentation, not eight unrelated generations.
